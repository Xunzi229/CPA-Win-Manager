# Mac 原生版按钮检查

本轮只修改 `mac/`，不改 Windows 实现。原生窗口通过 IPC 调用 Rust；下载安装等业务复用包内 Mac Python worker，无 HTTP 服务、无浏览器界面。

| 区域 | 按钮 | 实际行为与修复 |
| --- | --- | --- |
| 导航 | 四个页签、设置入口、弹窗关闭 | 保持原有绑定，增加脚本初始化与切换回归 |
| 服务 | 检查最新版、安装/升级 | 获取 GitHub Release，匹配当前 Mac 架构，校验下载；首次安装可点击；安装保留配置、备份旧文件 |
| 服务 | 启动、停止、重启 | 使用各项目 Mac 启动参数，只匹配当前目录的可执行文件；不再按进程名称全局终止 |
| 服务 | 打开后台 | 重新读取当前目录的实际端口并检查服务存活；使用系统默认浏览器打开后台，未运行或不可达时明确报错 |
| 服务 | 录入 Key、复制 Key、重新读取 Key | 密码输入、0600 私有文件原子保存；调用原生 pbcopy，失败明确反馈；独立读取缓存和日志，不联网 |
| 服务 | 选择解压目录、手工编辑目录 | 原生目录选择器，保存配置，清除旧目录的版本缓存 |
| 服务 | 清空安装备份 | 删除后端识别的备份目录，返回真实数量；有确认、失败反馈 |
| 软件 | 行检查、行安装 | 修正 package/portable 路由写反；检查和安装进入真实任务 |
| 软件 | 全部检查 | 按记录逐项检查，单项失败不妨碍剩余记录；汇总失败，不伪报成功 |
| 软件 | 下载全部待更新 | 仅处理待更新记录；只下载，不自动打开安装器 |
| 软件 | 刷新本地版本、关联、取消关联 | 重新读取真实 .app 版本；手工取消关联不自动重绑 |
| 软件 | 选择解压目录添加、GitHub 地址添加、软件库添加 | 输入与目录弹窗可用；规范仓库地址，拒绝重复记录 |
| 软件 | 检查/获取附件、编辑仓库及保留目录 | 补充缺失处理器，修改配置后保存；附件按 Mac 架构自动匹配 |
| 软件 | 移除记录 | 仅移除配置，不删除软件或用户文件 |
| 软件 | 打开目录、打开下载目录 | 校验非空绝对路径，真实打开 Finder，错误反馈 |
| 软件 | 清空全部下载包 | 只清理管理器实际下载并登记、且 SHA256 未改变的文件；保留其他下载、符号链接及被修改的文件 |
| 软件 | 移至废纸篓 | 仅处理关联到用户 Applications 的 .app；要求退出软件，保护管理器与系统应用，不删除个人配置 |
| 任务 | 取消 | 通知下载器取消，等待文件操作安全结束；不提前显示完成 |
| 设置 | 代理、下载目录、并发数、预发布开关 | 保持原生配置持久化与范围校验，目录按钮使用原生选择器 |
| 设置 | 检查管理器更新、发布页 | 真实查询管理器 GitHub Release；发布页由用户主动点击打开 |
| 设置 | Mac 健康自检 | 读取真实系统版本、磁盘、端口等；不再返回写死数据 |

## 明确限制

- Plus 页面可见时每 5 秒读取 Key；切换页面与手动读取立即刷新，旧读取结果不会覆盖刚录入的 Key。数据库只有摘要，无法恢复原文；首次初始化日志有明文时可捕获，重启已有服务不会生成新 Key。录入仅保存副本，不修改或重置真实凭据；未读取到 Key 时禁用复制。

- 安装包行的最新发布版本与自动匹配附件列直接提供下拉选择框，支持分页历史版本、当前 Mac 架构附件、自动匹配与固定版本；选择即时持久化保存，无需单独弹框，批量下载遵循所选目标且不自动降级。缺失附件会报错，不会静默换包；安装包行双击编辑尚未实现。
- 安装包“安装”会下载并打开 DMG/PKG 等文件，实际安装由 macOS 向导完成；批量下载不等于批量安装。
- Mac 应用的 ZIP 发布包也可自动匹配，安装按钮交给系统解压；内置业务组件附带 CA 证书，不依赖另一台 Mac 的 Python/OpenSSL 安装路径。
- 管理器更新按钮前往发布页手工下载，不执行原地自动替换应用包。
- PKG 软件不能通用卸载，需按厂商说明操作；未关联 .app 的废纸篓按钮禁用。
- 本轮前下载的文件没有可验证的管理器下载登记，不自动清理，防止误删用户 Downloads。
- 软件库搜索结果不保证存在适合 Mac 的发布附件，检查时会明确报错。
- GitHub API 限流时使用同一代理读取 Release 网页，发送 HTML 请求头，避免网站返回 406；网页也不可用时保留实际错误反馈。
- 自动测试使用临时目录与模拟下载；不在用户现有软件上执行升级、卸载或清空操作。
